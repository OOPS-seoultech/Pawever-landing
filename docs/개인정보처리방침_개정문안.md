# 개인정보 처리방침 개정 문안

## 총칙

습관적마케팅(이하 "회사")은 반려동물 추모 및 케어 서비스 'Pawever'(이하 "서비스")를
제공하면서 이용자의 개인정보를 보호하고 이와 관련한 고충을 신속하고 성실하게 처리하기 위하여
다음과 같이 개인정보 처리방침을 수립·공개합니다.

---

## 제1조 (수집하는 개인정보의 항목 및 수집 방법)

회사는 서비스 제공을 위해 다음 정보를 수집합니다.

### 1. 회원 가입 — 소셜 로그인 제공처로부터 수집

회사는 별도의 회원가입 절차를 두지 않으며, 카카오·네이버·애플 로그인을 통해서만 가입할 수
있습니다. 아래 항목은 이용자가 각 제공처의 동의 화면에서 동의한 범위에서 회사로 전달됩니다.

| 제공처        | 구분 | 수집 항목                                           |
| ------------- | ---- | --------------------------------------------------- |
| 카카오·네이버 | 필수 | 이름, 휴대전화번호, 연령대                          |
| 카카오·네이버 | 선택 | 이메일, 성별, 생일, 출생연도, 닉네임, 프로필 이미지 |
| 애플          | 필수 | 이메일                                              |
| 공통          | 필수 | 소셜 회원번호(제공처가 부여한 식별값)               |

- 선택 항목에 동의하지 않아도 서비스를 이용할 수 있으며, 해당 항목은 저장되지 않습니다.
- 애플 로그인은 이름·휴대전화번호를 제공하지 않습니다. 애플로 가입한 이용자는 서비스 내에서
  직접 입력하는 시점에 해당 항목이 수집됩니다.
- 애플 로그인의 경우 탈퇴 시 계정 연동을 해제하기 위한 토큰을 함께 저장합니다.

### 2. 서비스 이용 중 — 이용자가 직접 입력

| 수집 항목                          | 구분 |
| ---------------------------------- | ---- |
| 이름, 닉네임, 휴대전화번호, 연령대 | 필수 |
| 가입 경로                          | 선택 |
| 프로필 사진                        | 선택 |
| 알림 수신 동의 여부 및 동의 시각   | 선택 |
| 마케팅 수신 동의 여부 및 동의 시각 | 선택 |
| 푸시 알림 수신을 위한 기기 토큰    | 선택 |

- 가입 경로는 주변 추천, 쓰레드, 인스타그램, 오프라인 소개, 기타(직접 입력) 중 선택합니다.

### 3. 서비스 이용 중 — 이용자가 생성하는 정보

- 반려동물 프로필: 이름, 생년월일, 성별, 체중, 중성화 여부, 품종, 사진, 임종일
- 추모관 댓글 및 신고 내역(신고 사유, 직접 입력한 내용 포함)
- 장례업체 후기 및 서비스 후기(별점, 본문, 첨부 이미지)
- 이별 준비·응급 안내의 진행 상태 기록
- 미션 참여 기록: 완료 여부, 첨부 사진, 음성 녹음과 그 길이·형식·파형

### 4. 설문 참여 — 익명 수집

회사가 운영하는 설문은 로그인 없이 참여하며, 이름·연락처 등 신원을 알 수 있는 정보를 받지
않습니다. 응답은 무작위로 생성된 식별값으로만 구분됩니다.

- 설문 문항에 대한 답변 및 직접 입력 내용
- 문항별·전체 응답 소요시간
- 유입 경로(UTM 파라미터), 광고 클릭 식별자
- 기기 범주(모바일·태블릿·데스크톱), 화면 크기, 언어 설정, 시간대
- (선택) 반려동물과의 경험을 서술한 사연

### 5. 굿즈 신청 — 배송을 위한 수집

굿즈 제작·발송이 확정된 이용자에게 아래 항목을 별도 동의를 받아 수집합니다.

- 보호자 이름, 휴대전화번호, 우편번호, 주소, 상세주소
- 반려동물 이름 및 사진
- 신청 굿즈 종류 및 직접 제안 내용

### 6. 2차 안내 신청 — 광고성 정보 발송을 위한 수집

- 이메일 주소

이 정보는 설문 응답과 연결하여 저장하지 않습니다.

### 7. 자동 수집 항목

서비스 이용 과정에서 다음 정보가 자동으로 생성·수집될 수 있습니다.

- 웹서버 접속 기록: **IP 주소**, 접속 일시, 요청 경로, 응답 상태, 브라우저 정보(User-Agent),
  연결 경로(Referer). 요청 경로에는 화면에서 조회에 사용한 값이 함께 담길 수 있으며,
  현재는 닉네임 중복 확인 시의 닉네임과 장례시설 조회 시의 위치 좌표가 이에 해당합니다.
- 애플리케이션 처리 기록: 요청 방식, 요청 경로, 응답 상태, 처리 소요시간, 회원 식별번호
  (오류가 발생했거나 처리가 지연된 요청에 한해 기록되며, IP 주소는 포함하지 않습니다)
- 웹 분석·광고 성과 측정을 위한 정보 — 제8조 참조

홈페이지에 접속할 때에는 호스팅·보안 사업자(Cloudflare)가 접속 IP 주소와 브라우저 정보를
처리합니다. 설문 응답과 굿즈 신청은 이 경로를 거치지 않고 회사 서버로 직접 전송됩니다.

### 8. 위치 정보

반려동물 장례시설을 가까운 순으로 보여주기 위해, 이용자가 기기 위치 권한에 동의한
경우에 한해 현재 위치의 좌표를 전달받습니다.

- 전달받는 항목: 위도, 경도
- **저장하지 않습니다.** 목록을 만드는 즉시 사용하고 버리며 데이터베이스에 남기지
  않습니다. 다만 위 7항의 접속 기록에 요청 주소의 일부로 최대 14일간 남습니다.
- 위치 권한에 동의하지 않아도 기본 지역을 기준으로 장례시설 목록을 볼 수 있습니다.

## 제3조 (개인정보의 보유 및 이용 기간)

회사는 이용 목적을 달성하면 지체 없이 해당 정보를 파기합니다.

| 대상                   | 보유 기간                                  |
| ---------------------- | ------------------------------------------ |
| 회원 정보              | 회원 탈퇴 시까지 (탈퇴 즉시 파기)          |
| 반려동물 정보          | 회원 탈퇴 시 연결 해제 (아래 단서 참조)    |
| 굿즈 신청 정보 및 사진 | 굿즈 발송일로부터 3주                      |
| 2차 안내 이메일        | 수집일로부터 1년 또는 수신 거부 시까지     |
| 설문 응답              | 수집일로부터 2년                           |
| 설문 사연              | 수집일로부터 2년 또는 동의 철회 시까지     |
| 미션 기록 및 음성 녹음 | 반려동물 프로필 삭제 또는 회원 탈퇴 시까지 |
| 위치 정보              | 저장하지 않음 (접속 기록에 최대 14일)      |
| 웹서버 접속 기록       | 14일                                       |
| 애플리케이션 처리 기록 | 7일 ~ 최대 30일                            |

- 회원이 작성한 추모관 댓글은 탈퇴 후에도 본문이 보존되며, 작성자와의 연결만 삭제되어
  누가 작성했는지 알 수 없는 상태가 됩니다. 다른 이용자가 이어 온 대화의 맥락을 지키기
  위한 처리입니다.
- 회원이 등록한 반려동물의 이름·생년월일 등 기본 정보는 탈퇴 후에도 보존되며, 회원과의
  연결이 삭제되어 누구의 기록인지 알 수 없는 상태가 됩니다. 추모관에 남은 다른 이용자의
  글이 대상을 잃지 않도록 하기 위한 처리입니다.
- 관계 법령에서 보존을 요구하는 경우 해당 법령이 정한 기간 동안 보관합니다.

## 제4조 (개인정보의 파기 절차 및 방법)

### 1. 파기 절차

- **회원 탈퇴**: 서비스 내 탈퇴 기능을 이용하면 아래가 즉시 처리됩니다.
  1. 이름, 연락처, 이메일, 성별, 생일, 닉네임, 소셜 회원번호, 기기 토큰 삭제
  2. 회원 프로필 사진 파일 삭제
  3. 반려동물과의 연결 해제, 미션·이별 준비·응급 안내 기록 삭제
  4. 반려동물 프로필 사진 파일 삭제
  5. 애플 로그인 이용자의 경우 애플 계정 연동 해제
- **굿즈 신청 정보 및 사진**: 굿즈 발송일로부터 3주가 지나면 자동으로 파기됩니다.
- **2차 안내 이메일**: 보유 기간이 지나거나 수신 거부 요청을 처리하면 자동으로 파기됩니다.
- **접속 기록**: 보유 기간이 지나면 자동으로 삭제됩니다.

### 2. 파기 방법

- 전자적 파일 형태의 정보는 복구할 수 없는 방법으로 영구 삭제합니다.
- 저장소에 보관된 이미지 파일은 원본을 삭제합니다.

## 제5조 (개인정보의 제3자 제공)

회사는 이용자의 개인정보를 제3자에게 제공하지 않습니다.

다만 다음의 경우에는 예외로 합니다.

1. 이용자가 사전에 동의한 경우
2. 법령에 특별한 규정이 있거나 수사기관이 법령이 정한 절차에 따라 요구하는 경우

## 제6조 (개인정보 처리의 위탁)

회사는 원활한 서비스 제공을 위해 다음과 같이 개인정보 처리 업무를 위탁하고 있습니다.

| 수탁자                | 위탁 업무                                   |
| --------------------- | ------------------------------------------- |
| Amazon Web Services   | 서버 운영, 데이터 보관, 이미지 저장 및 전송 |
| Google LLC (Firebase) | 푸시 알림 발송                              |
| Cloudflare, Inc.      | 홈페이지 호스팅 및 접속 보안                |
| Google LLC            | 웹 이용 현황 분석                           |
| Meta Platforms, Inc.  | 광고 성과 측정 및 광고 최적화               |

회사는 위탁 계약 시 개인정보가 안전하게 관리되도록 필요한 사항을 규정하고 있으며,
위탁 업무나 수탁자가 변경될 경우 본 방침을 통해 공개합니다.

## 제7조 (개인정보의 국외 이전)

회사는 웹 분석, 광고 성과 측정 및 알림 발송을 위해 아래와 같이 개인정보를 국외로 이전합니다.
이전은 이용자가 해당 페이지에 접속하거나 알림이 발송되는 시점에 정보통신망을 통해
자동으로 이루어집니다.

| 이전받는 자          | 국가 | 이전 항목                                                   | 이전 목적                  | 보유 기간              |
| -------------------- | ---- | ----------------------------------------------------------- | -------------------------- | ---------------------- |
| Google LLC           | 미국 | 유입 경로, 페이지 이용 기록, 기기 범주, 브라우저 정보       | 웹 분석 및 서비스 개선     | 최대 14개월            |
| Meta Platforms, Inc. | 미국 | 페이지 조회 및 전환 이벤트, 브라우저 정보, 광고 클릭 식별자 | 광고 성과 측정 및 최적화   | Meta 정책에 따름       |
| Google LLC           | 미국 | 기기 토큰, 알림 제목 및 본문                                | 푸시 알림 발송             | 발송에 필요한 기간     |
| Cloudflare, Inc.     | 미국 | 접속 IP 주소, 브라우저 정보                                 | 홈페이지 전송 및 접속 보안 | Cloudflare 정책에 따름 |

홈페이지는 전 세계에 분산된 서버망을 통해 전송되며, 접속 시점의 연결 상태에 따라
국내 또는 국외 서버가 사용됩니다.

**이전 거부 방법**

브라우저의 쿠키 차단 설정이나 광고 차단 확장 프로그램을 이용해 웹 분석·광고 목적의
국외 이전을 거부할 수 있습니다. 거부하더라도 설문 응답과 굿즈 신청에는 제한이 없습니다.
푸시 알림은 서비스 내 알림 설정을 해제하면 발송되지 않습니다.

홈페이지 전송에 사용되는 서버망은 홈페이지 접속 자체에 필요하여 거부할 수 없습니다.
이 경우 처리되는 정보는 접속 IP 주소와 브라우저 정보로 한정되며, 설문 응답과 굿즈
신청 내용은 포함되지 않습니다.

**이전하지 않는 정보**

설문 답변, 이름, 연락처, 배송지, 반려동물 사진은 국외로 이전되지 않습니다.
회원 정보와 설문·굿즈 신청 정보는 국내(서울 리전)의 서버와 저장소에 보관됩니다.

## 제8조 (자동 수집 장치의 설치·운영 및 거부)

### 1. 회사가 설치하는 쿠키

회사는 이용자의 브라우저에 쿠키를 설치하지 않습니다. 다만 서비스 이용에 필요한 다음
정보를 브라우저 저장 공간에 보관합니다.

- 세션 저장 공간(브라우저 종료 시 삭제): 유입 경로, 페이지 체류시간, 작성 중인 설문 답변
- 로컬 저장 공간: 화면 테마 설정

### 2. 외부 도구가 설치하는 쿠키

아래 도구는 이용자를 구분하기 위해 자체적으로 쿠키를 설치합니다.

| 도구               | 수집·전송 정보                                                             |
| ------------------ | -------------------------------------------------------------------------- |
| Google Analytics 4 | 유입 경로, 페이지 경로, 설문 진행 이벤트, 기기 범주 및 화면 크기, 체류시간 |
| Meta Pixel         | 페이지 조회, 설문 시작·완료, 신청 완료 시점, 광고 클릭 식별자              |
| Google Tag Manager | 위 정보를 각 분석 도구로 전달하는 통로 역할                                |

Meta Pixel은 이메일·휴대전화번호를 변환하여 전송하는 기능(고급 매칭)을 사용하지 않습니다.
설문 답변, 이름, 연락처, 배송지, 반려동물 사진은 위 도구로 전송되지 않습니다.

### 3. 거부 방법

이용자는 브라우저 설정에서 쿠키 저장을 거부하거나 저장된 쿠키를 삭제할 수 있습니다.
쿠키를 거부해도 서비스 이용과 설문 참여, 굿즈 신청에는 제한이 없습니다.

## 제11조 (개인정보의 안전성 확보 조치)

회사는 개인정보의 안전한 처리를 위해 다음 조치를 취하고 있습니다.

1. **암호화**: 이름, 휴대전화번호, 이메일, 주소, 설문 사연, 장례업체 후기 본문은 국제 표준 암호화
   알고리즘(AES-256)으로 암호화하여 저장합니다. 중복 확인이 필요한 항목은 원본을 복원할 수
   없는 형태로 변환한 값을 별도로 사용합니다.
2. **접근 통제**: 개인정보에 접근할 수 있는 담당자를 최소한으로 제한하고, 개인정보가 포함된
   자료의 내려받기는 별도 인증 수단이 있어야 가능하도록 통제합니다.
3. **비공개 저장**: 굿즈 신청 사진은 외부에서 직접 접근할 수 없는 저장소에 보관하며,
   허가된 요청에 한해 일정 시간만 유효한 경로로 제공합니다.
4. **저장 최소화**: 접속 기록은 보안·오류 확인에 필요한 최소한의 항목만 남기고 정해진
   기간이 지나면 자동으로 삭제합니다. 애플리케이션 처리 기록에는 IP 주소를 남기지 않으며,
   오류가 발생했거나 처리가 지연된 요청만 기록합니다.
